# UNIOSUN Regularisation CBT Arena (2026) 🏛️

A mobile-first, gamified Computer-Based Testing (CBT) practice arena and exam simulator specifically designed for the **Osun State University (UNIOSUN)** Staff Regularisation Assessment.

### 🌟 Features
- **200 High-Yield Questions** across all 4 assessment pillars:
  - 💻 Core Subject Competence: Information Technology & Computing (80 Questions)
  - 🏛️ General University Knowledge & Osun State Fact Sheet (50 Questions)
  - 📚 Pedagogy, Higher Education Practice & Research Ethics (40 Questions)
  - 🧠 General Aptitude, Current Affairs & Logic (30 Questions)
- **Gamified Academic Progression**: Climb from *Graduate Assistant* (Level 1) to *Substantive Vice-Chancellor & Council Chair* (Level 9).
- **Audio Synthesizer Engine**: 100% client-side synthesized sound effects using the Web Audio API.
- **PWA & Offline Enabled**: Installable on Android & iOS home screens, works completely offline without network connection.
- **Full 60-Question Mock CBT Exam**: Timed 45-minute simulation with interactive Question Navigation Matrix.
- **High-Yield Cram Sheet**: Instant quick-reference drawer for Principal Officers, dates, CCMAS 70/30, Bloom's Taxonomy, and state leadership.
- **Clean Academic White Theme**: High-contrast, sunlight-readable UI with instant dark mode toggle.
